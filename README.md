## 📂 Estructura y Organización del Repositorio
Para mantener un entorno limpio y fácil de auditar, los archivos están distribuidos de la siguiente manera:

* **Ejercicios de código (`.psc`):** Agrupados por sesiones o carpetas dedicadas a los algoritmos en PSeInt.
* **Gráficas y Diagramas (`.svg`):** Las representaciones visuales y diagramas de flujo de cada proceso se encuentran en su respectiva sección de diagramas.
* **Documentación y Cuadros de Decisión:** Cada sesión o módulo cuenta con sus respectivas tablas de reglas de negocio, análisis y trazas de escritorio detalladas en archivos de soporte.
